宝贝课程管家｜个人手机网页 App

文件：
- index.html：应用主体，数据保存在当前浏览器 localStorage。
- manifest.json / service-worker.js：安装型网页应用配置（部署到 HTTPS 后可用）。
- icon.svg：主屏幕图标。

重要：
1. 这是免费、单人使用版本，不需要账号或订阅。
2. 数据默认只保存在当前浏览器/设备。请定期在“月度报告”页导出备份。
3. 要像 App 一样添加到 iPhone 主屏幕，需要把这些文件放到一个 HTTPS 静态网站上。
4. 目前没有替用户发布到公共网址；免费发布可用 GitHub Pages，但需要 GitHub 账号并按步骤上传文件。
